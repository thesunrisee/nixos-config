# NixOS Configuration

Modular NixOS configuration using **Flakes**, **Home Manager**, and **KDE Plasma 6**.

## Features

- Flake-based setup with `nixpkgs` + `home-manager` (locked via `flake.lock`)
- Clean module split: system-level modules vs. Home Manager modules
- KDE Plasma 6 + SDDM login manager, PipeWire audio, xdg-desktop-portal
- zram swap, automatic GC + store optimization, host firewall
- `nix fmt` formatting via `nixfmt` (RCF-style)
- Everything versioned in git

## Repository layout

```
.
├── flake.nix                    # flake entry: formatter + home-manager wiring
├── flake.lock
├── configuration.nix            # host entry point (thin, only imports)
├── hardware-configuration.nix   # GENERATED per-machine — do not reuse as-is
├── modules/                     # system-level modules
│   ├── base.nix                 # boot, networking, timezone, locale, users, zram, GC, firewall
│   ├── desktop.nix              # SDDM + Plasma 6 + xdg portal + polkit
│   ├── services.nix             # printing (CUPS), PipeWire, power profiles + powertop
│   ├── apps.nix                 # GUI apps (Brave, Obsidian, OnlyOffice, MPV, ...)
│   ├── development.nix          # dev toolchains (git, nodejs, python, go, editors)
│   └── terminal.nix             # fish binary + terminal fonts
└── home/                        # Home Manager modules (user alharis)
    ├── default.nix              # user metadata + env vars + sub-module imports
    ├── shell.nix                # fish, starship, zoxide, fzf, kitty, CLI essentials
    ├── editors.nix              # neovim, git config, LSP servers
    └── apps.nix                 # user-level apps (btop, fastfetch, lazygit, gh)
```

## Prerequisites

- NixOS 26.05+ with `nix-command` and `flakes` experimental features enabled
- `git` for cloning

## Using this config on your machine

This repo is a **personal machine configuration** — do not apply it blindly.

1. **Generate your own hardware config** (`hardware-configuration.nix` contains
   machine-specific disk UUIDs, CPU, and filesystem layout):
   ```sh
   sudo nixos-generate-config --root /mnt
   ```
   On an already-installed system, copy the file from
   `/etc/nixos/hardware-configuration.nix` of that machine.

2. **Adjust your identity** in `modules/base.nix`:
   - `networking.hostName`
   - `users.users.<your-user>` and its `extraGroups`
   - `time.timeZone` / `i18n.defaultLocale` if needed

3. **If you use Home Manager**, update:
   - `home/default.nix` — `home.username`, `home.homeDirectory`
   - `flake.nix` — the `home-manager.users.<your-user>` block

4. **Apply the configuration**:
   ```sh
   sudo nixos-rebuild switch --flake /etc/nixos#nixos
   ```
   > Test a generation without switching to it permanently with
   > `sudo nixos-rebuild boot --flake .#nixos`.

5. **Format the code**:
   ```sh
   nix fmt
   ```

## Tips

- `hardware-configuration.nix` is generated by `nixos-generate-config` — do not
  hand-edit it; regenerate instead.
- Everything machine-specific (UUIDs, hostname, username) is kept in a handful
  of obvious places, so adapting this config to another machine is quick.
- CLI tools used interactively live in `home/` (user scope); system services
  and their tooling live in `modules/` (system scope).
